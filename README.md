### GPS Marcador de Pontos

Aplicativo Android para registrar e consultar pontos de interesse usando localização GPS.

- **Baixar na Google Play:** https://play.google.com/store/apps/details?id=com.engsoft7.gpspontos&hl=pt
- **Documentação:** https://engsoft7.github.io/GPS-marcador-de-pontos/
- **Política de privacidade (português):** https://engsoft7.github.io/GPS-marcador-de-pontos/privacidade.html
- **Privacy policy (English):** https://engsoft7.github.io/GPS-marcador-de-pontos/privacy.html

## Publicação do site

Este repositório publica o site principal da Engsoft7 pelo GitHub Pages.

- `index.html` — página inicial do site.
- `app-ads.txt` — declaração de vendedores autorizados para publicidade.
- `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-*.png` — ícones do site (aba, favoritos e tela inicial).
- `site.webmanifest` — nome e ícones usados ao adicionar o site à tela inicial.
- `README.md` — informações sobre o site e o aplicativo.

O arquivo `app-ads.txt` deve estar disponível na raiz do domínio:
https://engsoft7.github.io/app-ads.txt
